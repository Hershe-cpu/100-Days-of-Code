# 100 Days of Code

This repository contains projects, exercises, and notes created during a "100 Days of Code" challenge. The primary focus is on Python, with some JavaScript projects included.

## Repository Structure

- days/ - Day-by-day project folders and notes
- projects/ - Larger individual projects
- scripts/ - Utility scripts used across exercises

> Languages: Python (primary), JavaScript

## How to run

Most projects include a README in their own folder with specific instructions. For typical Python projects:

1. Create a virtual environment:

   python -m venv .venv
   source .venv/bin/activate  # macOS/Linux
   .\.venv\Scripts\activate   # Windows

2. Install dependencies (if any):

   pip install -r requirements.txt

3. Run the project or script, e.g.:

   python main.py
